## 0.1.1 修正與實機回歸（2026-10-26）

- JDK 21 release 編譯與 lint 通過：0 errors、3 warnings（target API、Gradle 新版本提示、舊版 backup 設定提示）。17 項純 Java 規則檢查通過，含 LINE 完整名稱大小寫處理與非部分比對。
- 使用原本機簽章金鑰覆蓋更新 V2339／Android 16，既有通訊錄及設定保留，APK 簽章驗證通過。
- 設定不按儲存即可保存秒數，離開再進入仍存在。以 15 秒驗證觸控重置：中途操作後，超過最初期限仍停在設定頁；新的期限過後回首頁。測後還原原本 60 秒。
- 修正 App 內操作與輔助操作服務的閒置來源不同步；NCDPhone 前景期間由 Activity 管理閒置，背景服務不介入。
- 已取得預設電話角色後，按鈕可再次進入系統預設 App 管理，未變更使用者已選角色。
- 首頁返回後十秒前為第 1 頁，十秒後換至第 2 頁；離開首頁到設定等待超過十秒，仍停在設定頁。程式在頁面切換及 onPause 移除輪播 callback，onResume／首頁進入重新排程。
- 綠色聯絡人撥號區域使用剩餘垂直空間的 63%，大聽筒圖示與 56sp 文字；實機檢視更新前 60% 版本已佔約半螢幕，最終版再加大至 63%。
- LINE 在實機成功送出搜尋、切換聊天結果，忽略英文字母大小寫找到唯一完整名稱；App 回報「LINE 搜尋測試成功，已找到唯一結果，未撥號」。測試模式不點擊聯絡人、不進行實際通話。
- 仍未測試真實撥號／視訊接通、GPS 簡訊與全部 Android／LINE 版本。不將搜尋成功視為完整視訊流程已驗收。

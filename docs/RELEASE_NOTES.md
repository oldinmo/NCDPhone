修正 LINE 視訊通話的閒置返回保護：

- 原本已辨識通話時會停止閒置返回，但找不到掛斷按鈕滿 45 秒時可能清除通話狀態。
- 現在送出視訊撥號後，持續保護，不因逾時、通話控制項隱藏或未知介面解除，因此不會因閒置一分鐘切回首頁。

- 保護狀態保存在本機，可在輔助服務重新連線時恢復。狀態無法辨識時保留保護；使用者回到 NCDPhone 且音訊已停止時解除。
- 尚未實際撥出 LINE 視訊驗證接通；184 項規則檢查涵蓋長時間未知介面、音訊活動、控制項消失、連續結束確認及手動清除。

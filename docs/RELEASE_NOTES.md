NCDPhone 0.1.4 測試版，Android 10 以上。

- 已在發布者 AdMob 帳號建立 NCDPhone Android App 與首頁橫幅，正式 ID 已套用到發佈 APK。
- 時間、日期與星期在左，氣象在右，合計佔首頁可用高度約 25%。
- 氣象改用中央氣象署公開鄉鎮預報，繁體中文顯示行政區、天氣、溫度及圖示，不顯示預報時間；不再查詢 MET Norway。
- 數字撥號頁加入大型 0–9、＊、＃鍵盤，以及清除、刪除、撥號與返回按鈕；長按與快速連點仍有防誤觸處理。

驗證：54 項規則檢查、release 建置與 lint 通過；V2339／Android 16 實機取得「臺中市北屯區／晴／25°C」，時間日期星期正常、25% 版面正確，鍵盤輸入及刪除成功。互動測試使用官方測試廣告，未撥電話、簡訊或點擊廣告。

AdMob 項目目前尚未連結受支援的商店／完成審核；建立正式 ID 不代表能立即放送廣告，GitHub 下載不等同商店上架。中央氣象署資料使用公開網站檔案，格式改版可能需要更新解析程式；尚未串接颱風警報。
